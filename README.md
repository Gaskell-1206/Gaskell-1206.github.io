# Shengjia Chen — Academic Website

Personal academic website for Shengjia Chen, a PhD candidate at the Icahn School of Medicine at Mount Sinai working on computational pathology, medical imaging, foundation models, and fairness in clinical AI.

Live site: <https://gaskell-1206.github.io>

The site is plain static HTML and CSS and is published with GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static HTTP server.
